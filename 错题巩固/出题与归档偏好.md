# 出题与归档偏好

## 家长已确认

- 数学常规练习采用五年级中等难度。家长反馈综合练习 01 偏浅。后续增加小数乘除逆推、统计解释、比较方案等需要自主列式的题，并用学校样卷和实际作答校准。
- 语文、数学、英语都可以参考学校试卷和孩子以前的错题出新题。
- 微信作为交卷入口，照片和批改记录归入这个知识库。

## 当前练习安排

短卷可按 45 分钟安排，完整卷参照学校 80 分钟单元卷，参照 [[学校实卷分析]] 安排基础运算、实际计费与提高题。后续可随题量调整。适合练习的检查方法包括对照题目单位、估算数量级、用逆运算核对结果。语文和英语的难度、时长由后续材料补充。

学生卷和家长答案分开保存。需要打印时，当前默认设备为爱普生 EPSON_L3550_Series_2，通常打印学生卷一份。以后试卷默认 A4 黑白（灰度）。支持自动双面的打印机优先双面打印，仅支持单面的直接单面打印。

按实卷对标时逐问核对已知条件、求解方向及作答要求。综合题的常规难度以校卷同类题为准；额外要求解释、纠错或跨档逆推时，先确认学校进度。

数学完整卷以个人错题为主要来源，按学校照片保留题型、提问方向和运算层数，每道变式小幅调整数字、情境或条件。配入课堂原卷里的常规题型；在家长版标出原错题编号，方便复盘。平均数先按已知人数和总量正向求解。

家里和出差时都希望直接对助手说“打印学生卷”。在家使用已验证的 EPSON_L3550_Series_2；外网使用绑定同一台家用设备且已验证的 Epson Remote Print 队列。远程队列待绑定。
